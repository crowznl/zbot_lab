def quat_apply(quat: torch.Tensor, vec: torch.Tensor) -> torch.Tensor:
    """Apply a quaternion rotation to a vector.

    Args:
        quat: The quaternion in (w, x, y, z). Shape is (..., 4).
        vec: The vector in (x, y, z). Shape is (..., 3).

    Returns:
        The rotated vector in (x, y, z). Shape is (..., 3).
    """
    # store shape
    shape = vec.shape
    # reshape to (N, 3) for multiplication
    quat = quat.reshape(-1, 4)
    vec = vec.reshape(-1, 3)
    # extract components from quaternions
    xyz = quat[:, 1:]
    t = xyz.cross(vec, dim=-1) * 2
    return (vec + quat[:, 0:1] * t + xyz.cross(t, dim=-1)).view(shape)
请问quat_apply((w, x, y, z), (a, b, c))return的代数表达式
【】A:
这是一个标准的四元数旋转向量公式（Rodrigues' rotation formula 的变体）。
给定四元数 $q = (w, x, y, z)$ 和向量 $\vec{v} = (a, b, c)$。
设四元数的向量部分为 $\vec{u} = (x, y, z)$。
该 Python 函数 `quat_apply` 实现的逻辑代数表达式为：

$$
\vec{v'} = \vec{v} + 2w(\vec{u} \times \vec{v}) + 2\vec{u} \times (\vec{u} \times \vec{v})
$$

其在三个坐标轴上的展开分量形式（即旋转矩阵 $\times$ 向量）如下：

$$
\begin{aligned}
x' &= a(1 - 2y^2 - 2z^2) + b(2xy - 2wz) + c(2xz + 2wy) \\
y' &= a(2xy + 2wz) + b(1 - 2x^2 - 2z^2) + c(2yz - 2wx) \\
z' &= a(2xz - 2wy) + b(2yz + 2wx) + c(1 - 2x^2 - 2y^2)
\end{aligned}
$$

在您的代码中，输入向量是 `axis_x = [1, 0, 0]`，即 $a=1, b=0, c=0$。
此时代入上述公式，结果 `base_dir_forward_w` 的分量仅保留 $a$ 对应的项：

$$
\begin{aligned}
x' &= 1 - 2y^2 - 2z^2 \\
y' &= 2xy + 2wz \\
z' &= 2xz - 2wy
\end{aligned}
$$

这也是为什么 `atan2(y', x')` 可以直接写成：
`atan2(2*(x*y + w*z), 1 - 2*(y*y + z*z))`

这正是常用的 **四元数转欧拉角(Yaw)** 的公式。

【】A:
可以简化。通过展开向量旋转和叉积的代数表达式，直接计算出前向向量（Forward Vector）在 World-X 和 World-Y 上的分量，从而由 `atan2` 求得 Yaw 角。

### 推导简述
1.  **基座 Z 轴向量旋转**:
    将 $\vec{v}=(0,0,1)$ 通过 $q=(w,x,y,z)$ 旋转得到 $\vec{s}$：
    $$s_x = 2(xz + wy)$$
    $$s_y = 2(yz - wx)$$
    $$s_z = (1 - 2x^2 - 2y^2)$$
    (只需关心前两个分量)

2.  **前向向量叉积**:
    重力 $\vec{g}=(0,0,-1)$ 与 $\vec{s}$ 叉乘得到前向向量 $\vec{f}$：
    $$f_x = g_y s_z - g_z s_y = 0 - (-1)s_y = s_y$$
    $$f_y = g_z s_x - g_x s_z = (-1)s_x - 0 = -s_x$$

3.  **计算 Yaw**:
    Yaw = atan2($f_y$, $f_x$) = atan2($-s_x$, $s_y$)
